🚀 COMO RODAR O JOGO
═══════════════════════════════════════════════════════════════════════════

OPÇÃO 1: Script Automatizado (Recomendado)
───────────────────────────────────────────
  $ cd dominion_arena_tatica
  $ chmod +x start.sh
  $ ./start.sh

  ✓ Inicia PostgreSQL em Docker
  ✓ Instala dependências do backend
  ✓ Inicia backend na porta 5000
  ✓ Instala dependências do frontend
  ✓ Inicia frontend na porta 3000

OPÇÃO 2: Manual com Controle Total
──────────────────────────────────
  Terminal 1: docker compose up -d postgres
  Terminal 2: cd backend && npm install && npm run dev
  Terminal 3: cd frontend && npm install && npm run dev

  Acesse: http://localhost:3000
